Delivered the E2 bounded large-artifact download core in extensions/http-client. Pure validation and verification rules live in download_plan.rs (record shape, absolute canonical root, confined relative path, 1-byte to 8 GiB expected length, 64-hex digest, chunk and timeout bounds, Content-Length agreement, length-then-digest verification) with no network or filesystem access; effects live in download.rs (root confinement, verified reuse without network, streamed SHA-256 hashing into a uniquely named temporary file, fsync, atomic rename, cleanup on every failure). Shared record-field helpers were extracted into fields.rs and reused by the existing request surface. Three defects were found by running the tests: two test-side (macOS /var symlink versus canonicalized root, and an error-text case mismatch) and one implementation-side (the documented 2xx-only rule was not enforced, so a 3xx without a Location header would have streamed a redirect body; now rejected with its own test). A self-inflicted test hang (a server thread waiting on a connection the client never made) was fixed by a detached accept loop. 21 crate tests pass over loopback listeners only; clippy is clean under workspace deny-pedantic; the full scripts/check gate passed with PASS pre-commit. Documented the contract, ordered behavior, evidence, and limitations (no resume, no parallel ranges, whole-transfer deadline, destination directory created even on failure) in docs/network-db-extensions.md. No sw-mlpl or demo-mlpl-libraries change was needed, so both request documents remain empty. Committed 3ce5b8c on main.
